# El pulso de la felicidad mundial — Fase 3

Starter de React + Vite con estructura visual basada en la Fase 2. Los gráficos y KPIs muestran marcadores hasta conectar el dataset real.

## Requisitos
- Node.js LTS y npm

## Instalación y ejecución
```bash
npm install
npm run dev
```
Abre la dirección local que Vite muestre (usualmente http://localhost:5173).

## Compilar
```bash
npm run build
npm run preview
```

## Siguiente paso
Agregar el CSV a `public/data/` y programar su carga, limpieza, cálculos, gráficos y mapa. No se muestran cifras inventadas.
