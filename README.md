# Equipo Serch
Autor: Sergio Alexander Sanchez Garcia

Descripción del proyecto: Dashboard interactivo sobre bienestar y desarrollo humano que explora la evolución de las puntuaciones de felicidad de distintos países durante 2015–2024 y su asociación con variables socioeconómicas, como PIB per cápita, apoyo social, esperanza de vida saludable, libertad, generosidad y percepción de corrupción.
